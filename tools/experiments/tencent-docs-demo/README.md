# 腾讯文档填报 Demo

双击 `index.html` 即可使用，无需启动 ProductionAssistant 或安装依赖。

1. 在「环境与模板设置」内填写测试网页地址（可暂时留空）、月份名称、公司 / 园区、起始列与行号，保存设置。
2. 在「填报测试」选择日期、填写四项测试值，或点击「填入示例数据」。
3. 生成预览，检查 A1 地址。在「模拟已有值」中填写不同数字可验证冲突；在「模拟条件」中验证登录失效、无权限和锚点不匹配。
4. 检查通过后点击「模拟填报并回读」。再次检查并执行会跳过相同值。

配置使用当前浏览器的 localStorage，可导出 / 导入 JSON；浏览器可能限制 file URL 的存储，保存失败会提示。不要在文档地址中填写凭据。模拟表格只存于当前页面，刷新清空。初始模板来自历史方案样例，不代表真实测试环境已经确认。

当前已实现：独立界面、应用内配置、日期 / 单元格计算、预览失效管理、模拟写前校验、冲突整批停止和模拟回读。`core.js` 保存可复用的计算与模拟逻辑，`index.html` 负责交互。

后续接入：收到测试网页后确认登录流程、工作表切换、名称框、读取 / 写入方式、锚点地址和自动保存标志，再实现 Playwright 专用浏览器会话。网页选择器必须以实际页面为准，当前没有预设选择器或声称已连接。Notion 和定时任务不在本次 Demo 内。

验证：在本目录运行 `node check.cjs`。交互测试复用仓库 Prototype 中已安装的 jsdom；无需增加依赖。真实网页登录、隐藏列、写入和服务端保存须在测试环境另行验收。
